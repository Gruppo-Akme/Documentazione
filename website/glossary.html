A

Admin API
Insieme di interfacce di programmazione esposte da Shopify per gestire in modo programmatico le risorse dello store (prodotti, temi, metafield), soggette a un sistema di rate-limiting basato su punti.
Admin GraphQL API
Interfaccia di programmazione moderna basata su GraphQL che consente ad app, sistemi esterni o integrazioni ERP di leggere e scrivere i dati amministrativi di un negozio e-commerce.
Agente
Entità autonoma in grado di percepire il proprio ambiente (tramite sensori o input dati), elaborare informazioni e compiere azioni (tramite attuatori o strumenti) per raggiungere un obiettivo specifico.
AI Gateway
Componente architetturale che funge da punto di ingresso unico per l'orchestrazione, l'instradamento e il monitoraggio delle chiamate verso modelli linguistici e servizi di IA.
AI SDK
Insieme di librerie e strumenti di sviluppo software progettati per integrare facilmente modelli linguistici (LLM) ed interazioni generatrici di testo nelle applicazioni.
Amazon Comprehend Medical
Servizio di AWS basato sull'intelligenza artificiale e sull'elaborazione del linguaggio naturale specializzato in ambito medico.
Angular
Framework di sviluppo open-source, basato su Typescript e guidato da Google, utilizzato per la creazione di applicazioni web a pagina singola di livello aziendale.
API REST
Application Programming Interface - Representational State Transfer: è un tipo di interfaccia di programmazione delle applicazioni che segue le regole di uno stile architetturale per sistemi web.
Assistente conversazionale
Programma software che sfrutta l'intelligenza artificiale per interagire con gli utenti tramite linguaggio naturale.
Audit
Valutazione sistematica, indipendente e documentata dell'infrastruttura tecnologica, dei software, delle procedure e delle politiche di sicurezza di un'organizzazione.
AWS
Amazon Web Services: Raccolta di servizi infrastrutturali offerti tramite cloud.
AWS Lambda
Servizio di calcolo serverless fornito da AWS, che permette di eseguire codice in risposta a specifici eventi senza dover gestire o configurare alcuna infrastruttura sottostante.
Axum
Framework per lo sviluppo web e la creazione di API, scritto in Rust.

B

Backoffice
Parte di un sistema informativo o di un software che gestisce le operazioni interne, l'amministrazione, i dati e la logica di business, non visibile all'utente finale.
Bedrock
Servizio gestito da AWS che permette di accedere a modelli di AI generativa ad alte prestazioni per creare e scalare app di AI.

C

C4
Sistema di notazione standardizzato per la progettazione e la mappatura dell'architettura del software.
ChatGPT
Assistente virtuale basato sull'intelligenza artificiale generativa e sugli LLM, sviluppato da OpenAI.
CI
Continuous Integration: pratica di sviluppo software che prevede l'integrazione frequente del codice e l'esecuzione automatizzata di verifiche e build.
Claude
Assistente virtuale basato sull'intelligenza artificiale generativa e sugli LLM, sviluppato da Anthropic.
Cloud-ready
Un'infrastruttura cloud-ready è un sistema informatico aziendale progettato, configurato e ottimizzato per poter migrare, integrarsi e interagire facilmente con i servizi di cloud computing senza richiedere una totale riprogettazione radicale dell'architettura esistente.
Container
Unità software leggera e autonoma che impacchetta un'applicazione insieme a tutto ciò di cui ha bisogno per funzionare.
Copilot
Assistente virtuale basato sull'intelligenza artificiale generativa e sugli LLM, sviluppato da Microsoft.
CRM
Customer Relationship Management: Insieme di strategie, processi aziendali e strumenti tecnologici che un'impresa utilizza per gestire, tracciare e migliorare tutte le interazioni con i clienti attuali e potenziali.
CSS
Cascading Style Sheets: Linguaggio informatico usato per definire la presentazione, la grafica e il design di documenti scritti in HTML, XHTML o XML.

D

Diff del Grafo
Operazione di confronto analitico tra due snapshot consecutivi del grafo per identificare entità create, eliminate, orfane o modificate.
Discord
Piattaforma di comunicazione vocale, video e testuale impiegata per i meeting di gruppo telematici e le sessioni di allineamento.
DPIA
Data Protection Impact Assessment: Processo di analisi preventiva che serve a descrivere un trattamento dei dati personali, valutarne la necessità e la proporzionalità e gestire i rischi per i diritti e le libertà delle persone.
DuckDB
Sistema di gestione di database relazionale in-process, open-source e orientato alle colonne, progettato specificamente per l'analisi dei dati (OLAP).
Durable Execution
Paradigma di programmazione in cui lo stato di un workflow viene salvato al termine di ogni fase, garantendo la ripresa automatica del processo dopo errori di rete, riavvii o limiti di frequenza.

E

EasyOCR
Libreria Python open-source basata su PyTorch e sviluppata da Jaided AI per il riconoscimento ottico dei caratteri (OCR).
Embassy
Framework asincrono open-source per il linguaggio Rust, progettato appositamente per la programmazione di sistemi embedded e microcontrolli.
ERP
Enterprise Resource Planning: Software gestionale integrato che le aziende usano per coordinare, automatizzare e gestire in un unico sistema tutte le attività operative e i processi di business quotidiani.
ETL
Extract Transform Load: sistema automatizzato che raccoglie dati grezzi da varie origini, li elabora e li trasferisce in un database centrale per l'analisi.

F

fast-whisper
Conosciuto anche come faster-whisper, è una reimplementazione ottimizzata del modello di riconoscimento vocale Whisper di OpenAI, progettata per essere drasticamente più veloce e consumare meno memoria.
FastMCP
Framework open-source scritto principalmente in Python e TypeScript. Progettato da Prefect per semplificare lo sviluppo di server e client basati sul MCP.
Flutter
Framework open-source creato da Google per lo sviluppo di interfacce utente.

G

GDPR
General Data Protection Regulation: Regolamento UE/2016/679 che tratta la protezione dei dati personali e la privacy.
Gemini
Assistente virtuale basato sull'intelligenza artificiale generativa e sugli LLM, sviluppato da Google.
GenAI
Intelligenza Artificiale Generativa: Ramo dell'intellgenza artificiale capace di creare nuovi contenuti originali in risposta a un prompt.
Git
Sistema software di controllo versione distribuito utilizzato per tracciare la cronologia e le modifiche ai file del repository.
GitHub
Piattaforma web di hosting per progetti software basata sul sistema di controllo di versione Git.
GitHub Actions
Piattaforma di integrazione e distribuzione continua (CI/CD) fornita da GitHub per automatizzare compilazione, test e deploy dei documenti.
GitHub Pages
Servizio di hosting statico offerto da GitHub utilizzato per pubblicare il sito web del gruppo e rendere accessibile la documentazione.
Glossario
Documento e sezione informativa del sito web contenente le definizioni formali dei termini tecnici o ambigui utilizzati nella documentazione di progetto.
GraphQL
Linguaggio di interrogazione e manipolazione dei dati open-source per API e un runtime per soddisfare query con dati esistenti.

H

Harness engineering
Disciplina che si occupa di progettare e costruire l'infrastruttura, il contesto, gli strumenti e le regole che circondano un modello di IA, trasformandolo in un agente autonomo, sicuro e affidabile.
HTML
HyperText Markup Language: standard universale utilizzato per creare e strutturare le pagine web.

I

In-memory
Tecnologia in cui i dati vengono elaborati e archiviati direttamente nella RAM del computer, anzichè su unità di memoria di massa.
Infrastructure as Code
Metodologia di gestione e provisioning dell'infrastruttura IT che utiizza file di configurazione e leggibili da macchina anziché processi manuali o strumenti interattivi.

J

Java
Linguaggio di programmazione ad alto livello, orientato agli oggetti e a tipizzazione statica.
Java Spring Boot
Framework open-source basato sulla Java Virtual Machine che semplifica e velocizza la creazione di applicazioni web e microservizi stand-alone.
JavaScript
Linguaggio di programmazione di alto livello, interpretato e multi-paradigma, utilizzato principalmente per rendere interattive e dinamiche le pagine web.
JSON
JavaScript Object Notation: è un formato testuale leggero e strutturato, progettato per lo scambio di dati tra applicazioni.

K

Kafka
Piattaforma open-source di streaming di eventi distribuito, utilizzata per raccogliere, elaborare, memorizzare e analizzare flussi di dati in tempo reale.
KNX IoT 3rd Party API
Standard sviluppato da KNX Association per permettere a dispositici e servizi software di terze parti di interagire facilmente con un impianto domotico KNX.
Kubernetes
Spesso abbreviato in K8s, è una piattaforma open-source per l'orchestrazione dei container.

L

LangChain4j
Framework open-source progettato per semplificare l'integrazione di funzionalità di AI e LLM all'interno di applicazioni scritte in Java.
Liquid
Linguaggio di templating open source creato da Shopify utilizzato per la generazione e il rendering dinamico delle viste e delle sezioni nei temi e-commerce.
LiteLLM
Libreria Python open-source che funge da proxy universale per interagire con oltre 100 LLM tramite un unico formato standardizzato.
LLM
Large Language Model: è un sistema di intelligenza artificiale avanzato progettato per comprendere, elaborare e generare testo in linguaggio naturale.

M

MariaDB
Sistema di gestione di database relazionali open-source.
Markdown
Linguaggio di markup leggero, progettato per formattare documenti in testo semplice in modo che possano essere facilmente letti così come sono o convertiti in altri formati.
MCP
Model Context Protocol: Standard aperto e open-source introdotto da Anthropic per connettere i modelli di intelligenza artificiale a dati, app e servizi esterni in modo sicuro e bidirezionale.
Mermaid
Libreria basata su JavaScript che permette di generare diagrammi e visualizzazioni di testo ispirandosi alla sintassi Markdown.
Message broker
Software intermediario che permette a diverse applicazioni, servizi o sistemi di comunicare e scambiare dati in modo asincrono.
MFA
Multi-Factor Authentication: Sistema di sicurezza informatica che richiede all'utente di verificare la propria identità utilizzando due o più metodi indipendenti prima di concedere l'accesso a un account o a un servizio.
Multi-tenancy
Architettura software in cui una singola istanza di un'applicazione e della relativa infrastruttura serve contemporaneamente più clienti o organizzazioni, chiamati tenant.
Multi-Tenant
Architettura software in cui un'unica istanza di un'applicazione serve più clienti distinti (tenant), garantendo la separazione logica e la sicurezza dei dati riservati di ciascuno.
MVP
Minimum Viable Product: versione iniziale e funzionale di un prodotto software dotata delle funzionalità essenziali per soddisfare i requisiti minimi e validare l'architettura con l'utente.

N

NATS
Sistema di messaggistica open-source ad alte prestazioni, progettato per la comunicazione tra microservizi e sistemi distribuiti.
Next.js
Framework open-source basato su React e sviluppato da Vercel, che serve a creare applicazioni e siti web full-stack pronti per la produzione.
NLP
Natural Language Processing: Ramo dell'intelligenza artificiale e della linguistica computazionale che studia come far interagire i computer con il linguaggio umano.

O

OAuth2
Open Authorization 2.0: Standard aperto di autorizzazione delegata, che consente a un'applicazione di terze parti di accedere a risorse protette per conto di un utente, senza dover condividere la password o le credenziali dell'utente con l'applicazione stessa.
OCR
Optical Character Recognition: è una tecnologia che permette di convertire immagini di testo in testo digitale modificabile e ricercabile da un computer.
OLAP
On-Line Analytical Processing: tecnologia software che consente di analizzare in modo rapido, interattivo e multidimensionale grandi quantità di dati aziendali.
Open-source
Software il cui codice sorgente è reso pubblico e acessibile, permettendo a chiunque di studiarlo, utilizzarlo, modificarlo e redistribuirlo.
OpenCode
Agente di programmazione basato sull'intelligenza artificiale, gratuito e open-source rilasciato con licenza MIT.
openWakeWord
Framework di rilevamento audio open-source specializzato nel riconoscere wake words.

P

pgvector
Estensione open-source per il database relazionale PostGreSQL che permette di memorizzare, indicizzare e interrogare vector embedding direttamente all'interno dello stesso database.
Piper
Sistema open-source di TTS basato su reti neurali, progettato per convertire il testo scritto in audio dal suono naturale ed espressivo lavorando interamente in locale.
PoC
Proof of Concept è dimostratore eseguibile, una prova di fattibilità che attesta l'adeguatezza rispetto ai requisiti
Polling
Tecnica in cui un sistema centrale o un programma interroga a intervalli regolari un dispositivo, una periferica o un server per verificare se ci sono dati da elaborare, modifiche di stato o richieste in corso.
PostgreSQL
è un DBMS di tipo open source, cioè un database management system orientato agli oggetti
Prompt
Input (testuale, grafico o numerico) che fornisce a un sistema un'istruzione per generare una risposta.
PWA
Progressive Web App: è un'applicazione web sviluppata con linguaggi standard del web, che si comporta in modo simile ad un'app nativa su dispositivi mobili o desktop.
Python
Linguaggio di programmazione ad alto livello, orientato agli oggetti e interpretato.

Q

Qdrant
Database vettoriale e motore di ricerca per similarità open-source scritto in Rust.

R

RAG
Retrieval-Augmented Generation: è una tecnica di intelligenza artificiale che migliora le risposte dei modelli linguistici collegandoli a una base di conoscenza esterna e aggiornata prima di generare l'output.
RBAC
Role-Based Access Control: Modello di sicurezza informatica che regola l'accesso a sistemi, applicazioni e dati in base al ruolo che l'utente ricopre all'interno di un'organizzazione.
React
Libreria JavaScript open-source utilizzata per creare interfacce utente, in particolare per applicazioni a pagina singola.
React Native
Framework open-source creato da Meta che permette di sviluppare applicazioni mobili native per iOS e Android utilizzando Javascript e React.
Redis
REmote DIctionary Server: Data store open-source in-memory, utilizzato principalmente come database non relazionale, cache e message broker
Rhasspy
Toolkit open-source per la creazione di assistenti vocali personalizzati.
RLS
è una feature di controllo e gestione di un database che limita quali righe possano essere visualizzate/modificate basandosi sull'ID dell'utente
Rule Engine
compontente software che esegue una logica predefinita, policies e if-then conditions separatamente dal core application code
Rust
Linguaggio di programmazione compilato e multi-paradigma progettato per essere sicuro e veloce.

S

Saas
Software-as-a-Service è una struttura tecnologica che permette a un'applicazione di essere ospitata sul cloud e resa disponibile a più clienti (chiamati tenant) tramite un comune browser web o un client leggero
SAL
Stato Avanzamento Lavori: Riunione periodica o documento di verifica che misura il progresso di un progetto software o tecnologico rispetto agli obiettivi, ai tempi e ai costi stabiliti.
Sentence-transformers

Shopify
Piattaforma e-commerce che offre strumenti, servizi e per rivenditori online
Silero VAD
Silero Voice Activity Detection: Modello di in intelligenza artificiale open-source e pre-addestrato per rilevare la presenza di una voce umana all'interno di un flusso audio.
Similarità coseno
Misura utilizzata in data science per calcolare quanto due vettori siano simili tra loro, indipendentemente dalla loro grandezza.
Snapshot del Grafo
Rappresentazione completa ed immutabile delle entità e delle loro relazioni in un dato istante di tempo, salvata ed archiviata per scopi di tracciamento e storico.
SQLite
Libreria software scritta in linguaggio C che implementa un motore di database relazionale di tipo SQL, senza server e auto-contenuto.
STT
Speech-to-Text: Tecnologia che converte automaticamente il linguaggio parlato in testo scritto.
SupaBase
piattaforma open-source di tipo BaaS costruita su un database relazionale SQL

Transformer

Trigger
Frammento di codice o procedura che viene eseguita automaticamente in risposta a un evento specifico, senza bisogno di un comando manuale.
TTS
Text-to-Speech: Tecnologia che converte automaticamente il testo scritto in un flusso audio con voce parlata.
Typescript

Typst

WhatsApp

Willow

Workflow
